# 安全测试清单

## 1. 测试目标

本系统当前采用“JWT 工具类 + Controller 手动鉴权”的方式进行权限控制，尚未使用统一 JWT 拦截器或 Spring Security 全局过滤机制。因此需要重点测试是否存在以下安全风险：

1. 未登录用户直接访问管理端接口。
2. 普通用户通过 API 访问管理员接口。
3. 伪造、缺失、过期或错误 Token 后接口仍返回敏感数据。
4. 某些 Controller 忘记手动鉴权，导致接口越权访问。
5. 前端路由拦截有效，但后端接口没有真正校验权限。
6. 通过服务器 API 获取知识库、咨询记录、情绪日志、用户信息等后台数据。

测试采用黑盒测试、白盒测试和灰盒测试相结合的方式进行。

## 10. 高风险接口优先级

优先测试以下接口，因为它们最容易造成后台数据泄露或数据破坏：

| 优先级 | 接口 | 风险 |
| --- | --- | --- |
| 高 | `/api/emotion-diary/admin/page` | 泄露用户情绪日志 |
| 高 | `/api/psychological-chat/sessions` | 泄露咨询会话 |
| 高 | `/api/psychological-chat/sessions/{sessionId}/messages` | 泄露聊天内容 |
| 高 | `/api/knowledge/article/{id}` DELETE | 非法删除文章 |
| 高 | `/api/knowledge/article/{id}/status` | 非法发布/下线 |
| 中 | `/api/file/upload` | 未授权上传文件 |
| 中 | `/api/user/profile` | 越权查看或修改用户信息 |
| 中 | `/api/knowledge/article/page` | 泄露草稿或下线文章 |
